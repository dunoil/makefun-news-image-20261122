A single 1024x1024 front page for the make.fun bounty news-image-20261122, summing up the world news of Sunday 22 November 2026. It carries 44 stories from 7 regions: 13 illustrated scenes, 31 one-line briefs, a numbered world map with 44 pins, a DAY IN NUMBERS strip, and a DATE CHECK footer naming stories deliberately excluded because they were first reported before 22 November 2026. The program is pure Node 22 standard library, runs with no network, and deterministically writes the PNG to /output/entry.png.
